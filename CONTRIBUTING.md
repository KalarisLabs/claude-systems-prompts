# Contributing to Claude System Prompts

Thank you for your interest in contributing! This repository is a living archive and research hub for understanding Anthropic's Claude models. We welcome contributions from researchers, developers, and AI enthusiasts.

<!-- Curated by Sayan Chowdhury -->

## How You Can Contribute

Contributions span the archived prompts and the analysis around them: **prompt updates, new model coverage, analysis, tooling, and documentation**.

### 1. Submit New Analysis or Findings
Have you found an interesting detail in one of the archived system prompts? Discovered a novel jailbreak or behavioral quirk?
- Open an Issue using the **Analysis Submission** template.
- If you have written a detailed markdown report, submit a Pull Request adding it to the `system-prompt/analysis/` or `highlights/` directories.

### 2. Prompt Updates
Anthropic periodically updates the system prompts on [platform.claude.com](https://platform.claude.com/docs/en/release-notes/system-prompts/overview). If you notice a newer dated version has been published for any of the 23 archived models:
- Open an Issue using the **Prompt Update** template.
- Provide the new prompt text (or a link to the official release-notes page) and the retrieval date.

### 3. Update the Archived Prompts (`models/`)
To refresh an existing archived prompt or add a newly published model:
1. Fetch the model's page from `https://platform.claude.com/docs/en/release-notes/system-prompts/<model-slug>`.
2. Copy the **latest dated** system prompt **verbatim**. No paraphrasing, no edits, no redactions. Keep Anthropic's `{{currentDateTime}}`-style placeholders untouched.
3. Replace `models/<model-slug>/system-prompt.md`, preserving the header format: model name, slug, latest version date, all published version dates (newest first), source URL, applies-to note, and retrieval date.
4. Update the index in `models/README.md` and the "Models at a Glance" table in `README.md` to match.

### 4. Interactive Tools and Visualizations
We welcome PRs that add interactive components to the repository, such as:
- Scripts to parse or visualize the prompt JSON tools.
- Comparison charts across models (e.g., Fable 5.2 vs Opus 5.5, Claude vs GPT-5.5, Claude vs Gemini 3).
- UI wrappers for exploring the prompts (e.g., a GitHub Pages site).

## Contribution Guidelines

1. **Maintain Formatting:** Please ensure your Markdown files are well-formatted and use standard GitHub Flavored Markdown.
2. **Verbatim First:** Archived prompt text must remain byte-for-byte faithful to Anthropic's official release notes. Fix typos in *your own* analysis, never in the archived prompt. If the source page itself looks wrong, note it in the PR instead of silently correcting it.
3. **Attribution:** When adding new files, please include appropriate attribution for your research, while maintaining the repository's baseline curation footers.
4. **No Malicious Content:** While we discuss safety classifiers and dual-use capabilities, do not submit PRs containing weaponized exploits or dangerous code generated by the model. Keep discussions academic and focused on the model's architecture.

## Getting Started

1. Fork the repository.
2. Create a new branch (`git checkout -b feature/your-analysis`).
3. Commit your changes (`git commit -m 'Add analysis on tool use'`).
4. Push to the branch (`git push origin feature/your-analysis`).
5. Open a Pull Request!

We review PRs regularly and appreciate your help in making this the premier resource for Claude system-prompt research.
